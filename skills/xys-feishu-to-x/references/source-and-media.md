# 飞书与素材处理

## 读取正文

先使用本机已有且已授权的飞书工具。`lark-cli` 可用时优先使用；不要求每位成员先安装同一套 CLI 才能工作。以下是既有 CLI 示例，具体命令与成功响应以当前 `--help` 及返回结果为准，不因弃用提示盲目升级或切换协议版本。

```sh
lark-cli api GET /open-apis/wiki/v2/spaces/get_node --as user --params '{"token":"WIKI_NODE_TOKEN"}'
lark-cli docs +fetch --doc 'DOCX_URL_OR_TOKEN' --as user
```

Wiki 先解析节点的 `obj_type`、`obj_token`，docx 才按文档读取。保留输入 URL 和实际文档标识作为同源别名；非 docx 内容按真实类型处理，不猜 token。

正文通常在 `data.markdown`、标题在 `data.title`。同时检查退出码、业务错误、分页字段与正文结尾；长返回可保存本地完整读取，不依赖被截断的终端输出。必要时读取 blocks 补齐内嵌文件和复杂结构：

```sh
lark-cli api GET /open-apis/docx/v1/documents/DOC_TOKEN/blocks --as user --params '{"page_size":500}'
```

遍历实际分页，依据 block 父子关系与正文确认阅读顺序。目录权限不足不等于单篇文档不可读，已知真实 docx 链接时可正常尝试直接读取，不能绕过访问控制。

CLI 不可用或失败时，使用当前工具正常打开已登录浏览器中的文章。滚动加载全部内容，检查折叠块、表格和正文结尾；浏览器只加载一部分时不能宣称读完。用工具支持的正常下载／媒体读取能力取得文件，不提取 Cookie、令牌或隐藏应用状态，不调用私有接口。

浏览器也无权读取时，说明具体文档和当前可见的登录身份，请使用者登录有权账号或取得阅读权限。不自动申请权限、调整分享设置或复制为公开文档。

## 素材清单

为本篇建立简单清单：来源标识、媒体类型、本地文件、正文位置、是否关键、检查结果。封面单独记录。图片、视频及视频海报分别计算，不能把视频封面算作额外正文图。

已取得本篇 media token 且 CLI 可用时，下载示例：

```sh
lark-cli api GET /open-apis/drive/v1/medias/MEDIA_TOKEN/download --as user --output ./01.download
```

文档媒体用 `medias` 路径。云盘文件下载报错不等于所有媒体接口无权；只按实际错误采取适当替代。校验真实格式和大小后再命名，不能把 JSON 错误回执当图片。每次只下载本篇需要的素材，保留原始文件。

- **图片**：逐张查看，确认与说明相符、文字可读、无无关隐私。不要重绘实测截图来补证据。必要脱敏另存副本。
- **视频**：用已有 `ffprobe`／`ffmpeg` 或系统能力检查容器、编码、时长、尺寸与音轨。需要时做完整解码检查，抽看关键画面；抽帧不能冒充完整试听。
- **兼容转换**：原 MP4 可能含 HEVC；网页拒绝时可另存兼容 MP4，再检查实际编码、时长、音轨和画面。GIF 可转换为保留帧序和时长的视频，上传后确认能动。不要仅凭扩展名判断。
- **音频**：若编辑器不能直接插入，可在保留完整音轨的前提下，用原文对应图或中性文字卡封装为视频，标明为音频演示，不伪称原文有视频。
- **提示词与附件**：原文要求完整展示的提示词、代码或歌词须保留。截图文字有疑点时回看或核对，不猜补。仅附件能说明关键步骤而当前无法读取时，将该项标为缺口。

不为上传限制截断剧情、删掉关键演示或只贴静态首帧。原文承诺的成片、操作截图等关键内容缺失时停在完整度检查前，保存其余成稿；纯装饰或无关重复素材可按编辑判断省略，并记录省略原因。旧素材缓存可以用于对照，未经核对不能冒充最新原稿。
